# Assets

Game jam theme: **TRICK** (deception, stunts, spells, heists, winning a trick in a card game).
Visual direction: **dark / gothic / occult casino**. Palette anchors: Dark Dwellers purple UI, cursed-object pixel icons, black-and-gold casino.

Status: **READY** = imported, style-matched, usable as is. **CHECK** = usable, needs a decision (style or licence). **MISSING** = not found yet.

## Network note

The build environment can only reach GitHub, GitLab and Bitbucket. itch.io, OpenGameArt, Kenney and Freesound are blocked, so new assets from there have to be added to the repo by hand.
